# Harness Manager · native design

## Direction

- **Product:** local skills, MCP configuration, and Pi bundle management for developers
- **Character:** exact, restrained, editorial
- **World:** technical indexes—white, graphite, fine rules
- **Moments:** large, honest inventory counts and a carefully aligned resource table
- **Signature:** monospace scope/path annotations paired with a bracket/index mark

The direction was approved before implementation. The later platform decision replaced the web UI with genuine SwiftUI, not a web wrapper.

## References

[FreeDesignMD Vault](https://freedesignmd.com/landingpage/vault-fintech) supplies typographic restraint, monochrome hierarchy, and disciplined rules—not its landing-page animations or financial subject. [Astryx](https://github.com/meta/astryx) informs component/state discipline. It is a React library and is not bundled in this SwiftUI app.

## Nine passes

1. **Spacing:** 4px rhythm; a 240px sidebar, 36px navigation rows, 32px content edges, consistent table cells and 24px panel padding
2. **Color:** white/graphite surface ramps with three text roles; a restrained sage accent for selection and the local-only indicator; no glow, hue gradients, or colored shadows
3. **Icons:** native SF Symbols at consistent control sizes; no emoji; an original bracket/index product mark
4. **Copy:** scope-led titles, explicit configured-versus-connected language, honest cache/resource states, and exact removal/restore consequences
5. **Type:** macOS system sans at regular/medium weights; 40px page titles, 36px figures, 12–14px interface text, monospace metadata and tabular figures
6. **Layout:** full desktop workspace; sidebar, contextual header, inventory summary, filters, table, optional inspector; Packages and Backups remain first-class sections
7. **Details:** 8px controls, 12px package panels, hairlines, keycaps, separate focus versus checkbox selection, protected-row explanations, full-path confirmation sheets
8. **Visuals:** actual native product content, not generated imagery; screenshots use an explicitly labelled synthetic home
9. **Motion:** no decorative loops or layout animation; native progress feedback is limited to actual scanning/mutation work; macOS controls retain system accessibility behavior

## Native interactions

SwiftUI Table handles row focus and native table behavior. Checkbox selection controls destructive intent independently. Native folder panels, Finder reveal, clipboard actions, application menus, keyboard shortcuts, Settings, and appearance support do not require a web runtime.

The app does not read or display command arguments, environment values, or server connection URLs. Scope, source, inheritance, package ownership, and protection states remain visible where decisions happen.
